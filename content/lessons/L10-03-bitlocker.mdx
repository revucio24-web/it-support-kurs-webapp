# Modul 10 – Lektion 3: BitLocker-Recovery und Verschlüsselung

## 1. Lernziele
- Du kannst BitLocker aktivieren und verwalten.
- Du kannst BitLocker-Recovery durchführen.
- Du kannst Recovery-Keys finden und nutzen.
- Du kennst die Unterschiede zwischen BitLocker und Geräteverschlüsselung.

## 2. Theorie kompakt

**BitLocker:** Festplattenverschlüsselung (Full Disk Encryption) in Windows Pro/Enterprise/Education.

**BitLocker vs. Geräteverschlüsselung:**
- **BitLocker:** Pro/Enterprise/Education; vollständig konfigurierbar; TPM + PIN/Passwort/USB-Key.
- **Geräteverschlüsselung:** Home; automatisch (wenn TPM + Secure Boot); eingeschränkt (kein PIN, keine Konfiguration).

**BitLocker-Komponenten:**
- **TPM (Trusted Platform Module):** Hardware-Chip (oder virtuell in VM); speichert Verschlüsselungsschlüssel.
- **Recovery Key:** 48-stelliger Schlüssel für Wiederherstellung (wenn TPM nicht verfügbar).
- **Protectors (Schutzmechanismen):**
  - TPM only (automatisch).
  - TPM + PIN.
  - TPM + USB-Key.
  - Passwort (für externe Laufwerke: BitLocker To Go).

**BitLocker aktivieren:**
- Systemsteuerung → BitLocker-Laufwerkverschlüsselung → "BitLocker aktivieren".
- Oder: Einstellungen → Datenschutz & Sicherheit → Geräteverschlüsselung (Home).
- Recovery Key speichern: In Datei, auf USB, in Entra ID/Azure AD, in AD.
- Verschlüsselung startet (im Hintergrund, PC nutzbar).

**BitLocker-Recovery (wann nötig):**
- TPM-Änderung (Mainboard-Wechsel, BIOS-Update).
- Boot-Konfiguration geändert.
- Zu viele fehlgeschlagene PIN-Versuche.
- TPM deaktiviert/deinstalliert.

**Recovery Key finden:**
- Entra ID/Azure AD: Entra ID Admin Center → Geräte → BitLocker Keys.
- AD: Active Directory Users and Computers → Computer → "BitLocker Recovery Password".
- Datei: Gespeicherte .txt-Datei.
- USB: Gespeicherter Key auf USB-Stick.
- Microsoft-Konto: account.microsoft.com → Geräte → BitLocker Recovery Key.

**BitLocker-Befehle (manage-bde):**
- `manage-bde -status C:` → Status (Verschlüsselung, Schutz).
- `manage-bde -protectors -get C:` → Protector-Liste (Recovery Key ID).
- `manage-bde -protectors -add C: -tpm` → TPM-Protector hinzufügen.
- `manage-bde -unlock C: -recoverypassword <Key>` → mit Recovery Key entsperren.
- `manage-bde -off C:` → Entschlüsselung starten.

## 3. Praxis-Übung im Homelab

Ziel: BitLocker aktivieren und Recovery durchführen (in VM).

Schritte (nur in VM!):
1. VM (Win11 Pro/Enterprise) → Systemsteuerung → BitLocker → "BitLocker aktivieren".
2. Recovery Key speichern (in Datei auf Shared Folder).
3. Verschlüsselung starten (dauert einige Minuten).
4. `manage-bde -status C:` → "Protection On".
5. Recovery simulieren: VM-Einstellungen → TPM entfernen → VM starten → Recovery-Bildschirm.
6. Recovery Key eingeben → Windows startet.
7. TPM wieder hinzufügen → `manage-bde -protectors -add C: -tpm` → Neustart → normaler Boot.
8. Aufräumen: BitLocker deaktivieren (optional) oder VM löschen.

**Erwartetes Ergebnis:** BitLocker aktiviert; Recovery durchgeführt; normaler Boot wiederhergestellt.

## 4. Berühmte Fehler + Lösungen

**Fehler 1: "Recovery Key verloren – Daten nicht zugänglich"**
- Symptom: PC startet nicht; Recovery Key unbekannt.
- Ursache: Key nicht gesichert (kein AD/Entra/Azure, keine Datei).
- Diagnose: Alle möglichen Speicherorte prüfen (AD, Entra, Azure, Datei, USB, Microsoft-Konto).
- Lösung: Wenn Key nicht gefunden → Datenverlust (Verschlüsselung nicht knackbar).
- Prävention: Key IMMER in Entra ID/Azure/AD sichern; Backup-Key; Dokumentation.

**Fehler 2: "BitLocker-Recovery nach BIOS-Update"**
- Symptom: Nach BIOS-Update startet PC in Recovery-Modus.
- Ursache: BIOS-Update ändert TPM-Messungen (PCR-Werte).
- Diagnose: Recovery-Bildschirm; BitLocker-Status.
- Lösung: Recovery Key eingeben; TPM neu initialisieren (manage-bde).
- Prävention: Recovery Key vor BIOS-Update sichern; TPM-Messungen dokumentieren.

**Fehler 3: "BitLocker-Entschlüsselung hängt"**
- Symptom: `manage-bde -off` oder GUI-Entschlüsselung bleibt bei X% hängen.
- Ursache: Disk-Problem; Systemauslastung.
- Diagnose: `manage-bde -status` → Fortschritt; Event Viewer.
- Lösung: Warten; System nicht ausschalten; bei Bedarf WinRE → Entschlüsselung.
- Prävention: Genug Akku/Strom; keine anderen Operationen während Entschlüsselung.

**Fehler 4: "Geräteverschlüsselung in Home nicht deaktivierbar"**
- Symptom: Home-User kann Geräteverschlüsselung nicht deaktivieren (keine Option).
- Ursache: Geräteverschlüsselung ist automatisch (Home); keine Konfigurationsoption.
- Diagnose: Einstellungen → Datenschutz & Sicherheit → Geräteverschlüsselung.
- Lösung: Nur über Registry/PowerShell (nicht empfohlen) oder Windows neu installieren.
- Prävention: Vor Aktivierung prüfen; Pro/Enterprise für volle Kontrolle.

## Ticket-Szenario zum Selbstlösen

**Ticket #11003:** "User: 'Mein Laptop startet nicht mehr. Es erscheint ein blauer Bildschirm mit 'BitLocker Drive Encryption Recovery' und verlangt einen Schlüssel.'"

**Lösung (aufklappbar):**
1. Informationen: Welcher PC? Wer ist der User? Hat er den Recovery Key?
2. Recovery Key suchen: Entra ID/Azure AD → Geräte → BitLocker Keys; oder AD; oder Microsoft-Konto; oder Datei/USB.
3. Key eingeben → Windows startet.
4. Ursache prüfen: BIOS-Update? TPM-Änderung? Boot-Konfiguration?
5. TPM neu initialisieren: `manage-bde -protectors -add C: -tpm`.
6. Dokumentieren; User über Recovery Key informieren (sicher aufbewahren).
