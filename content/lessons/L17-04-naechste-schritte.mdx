# Modul 17 – Lektion 4: Nächste Schritte und Zertifizierungen

## 1. Lernziele
- Du kennst relevante IT-Zertifizierungen für Support/Admin.
- Du kannst einen Karrierepfad planen.
- Du kennst Weiterbildungsmöglichkeiten.
- Du kannst nächste Schritte definieren.

## 2. Theorie kompakt

**Zertifizierungen für IT-Support/Admin:**

| Zertifizierung | Anbieter | Level | Fokus | Kosten (ca.) |
|---|---|---|---|---|
| **CompTIA A+** | CompTIA | Entry | Hardware, OS, Troubleshooting, Security | ~$500 (2 Prüfungen) |
| **CompTIA Network+** | CompTIA | Entry-Mid | Netzwerk, Infrastruktur | ~$350 |
| **CompTIA Security+** | CompTIA | Entry-Mid | Security, Compliance | ~$400 |
| **ITIL 4 Foundation** | PeopleCert | Foundation | ITSM, Incident/Problem/Change | ~$400 |
| **Microsoft 365 Certified: Modern Desktop Administrator (MD-102)** | Microsoft | Associate | Windows 11, Intune, M365 | ~$165 |
| **Microsoft Certified: Azure Administrator (AZ-104)** | Microsoft | Associate | Azure, IaaS, PaaS | ~$165 |
| **Microsoft Certified: Identity and Access Administrator (SC-300)** | Microsoft | Associate | Entra ID, Conditional Access, MFA | ~$165 |
| **Cisco CCNA** | Cisco | Associate | Netzwerk, Routing, Switching | ~$300 |
| **Google IT Support Certificate** | Google/Coursera | Entry | IT-Support Grundlagen | ~$300 (Coursera) |

**Karrierepfade:**

```
Level 1 Support → Level 2 Support → Level 3 / Spezialist
                      ↓
            System Administrator → Senior Admin → IT Manager
                      ↓
            Cloud Admin (Azure/AWS) → Cloud Architect
                      ↓
            Security Analyst → Security Engineer → CISO
```

**Weiterbildungsmöglichkeiten:**
- **Praktische Erfahrung:** Homelab, Open-Source-Projekte, Freelance.
- **Kurse:** Microsoft Learn (kostenlos), Coursera, Udemy, Pluralsight.
- **Community:** Reddit (r/sysadmin, r/ITCareerQuestions), Discord, Meetups.
- **Mentoring:** Erfahrene Kollegen, LinkedIn.

**Nächste Schritte (nach diesem Kurs):**
1. **Homelab ausbauen:** Mehr VMs, AD-Lab, Netzwerk-Lab.
2. **Zertifizierung:** CompTIA A+ oder ITIL 4 Foundation (je nach Interesse).
3. **Praktische Erfahrung:** Freiwilligenarbeit, Praktikum, Junior-Position.
4. **Spezialisierung:** Cloud (Azure/AWS), Security, Netzwerk, DevOps.
5. **Netzwerk aufbauen:** LinkedIn, Meetups, Community.

**Empfohlene Reihenfolge:**
1. CompTIA A+ (Grundlage, von diesem Kurs gut vorbereitet).
2. ITIL 4 Foundation (ITSM-Vokabular).
3. Microsoft MD-102 (Windows 11/Intune).
4. Spezialisierung nach Interesse.

## 3. Praxis-Übung im Homelab

Ziel: Karriereplan erstellen.

Schritte:
1. Selbstreflexion: Was hat mir am meisten Spaß gemacht? (Hardware, Netzwerk, Security, Cloud, Support).
2. Zertifizierungsplan erstellen: Welche Zertifizierung als nächstes?
3. Lernplan: Zeitrahmen, Ressourcen, Budget.
4. Homelab-Plan: Was will ich als nächstes labben?
5. Netzwerkplan: LinkedIn-Profil, Community-Beitritt.
6. Dokumentieren: Karriereplan (z. B. `C:\Lab\Karriereplan.md`).

**Erwartetes Ergebnis:** Karriereplan erstellt; nächste Schritte definiert.

## 4. Berühmte Fehler + Lösungen

**Fehler 1: "Zu viele Zertifizierungen gleichzeitig"**
- Symptom: Überfordert; keine Zertifizierung abgeschlossen.
- Ursache: Zu viele Ziele parallel.
- Diagnose: Lernplan prüfen.
- Lösung: Priorisieren; eine Zertifizierung nach der anderen.
- Prävention: Fokus; realistische Ziele.

**Fehler 2: "Nur Theorie, keine Praxis"**
- Symptom: Zertifizierung bestanden, aber keine praktische Erfahrung.
- Ursache: Kein Homelab; keine praktischen Übungen.
- Diagnose: Praktische Erfahrung prüfen.
- Lösung: Homelab ausbauen; praktische Projekte.
- Prävention: Theorie + Praxis kombinieren.

**Fehler 3: "Kein Netzwerk – keine Opportunities"**
- Symptom: Keine Job-Angebote; isoliert.
- Ursache: Kein Networking.
- Diagnose: LinkedIn-Profil; Community-Beitritt.
- Lösung: LinkedIn-Profil erstellen; Meetups besuchen; Community beitreten.
- Prävention: Networking als Teil der Karriereplanung.

**Fehler 4: "Zertifizierung abgelaufen – nicht erneuert"**
- Symptom: Zertifizierung nicht mehr gültig.
- Ursache: CE (Continuing Education) nicht erfüllt.
- Diagnose: Zertifizierungsstatus prüfen.
- Lösung: CE-Credits sammeln; Prüfung wiederholen.
- Prävention: CE-Anforderungen kennen; Kalender-Erinnerung.
